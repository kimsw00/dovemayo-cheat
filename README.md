# Dovemayo Infinite Rainbow

dovemayo.com 스네이크 미니게임 보조 확장프로그램 (비공식 팬 제작물)

## 기능
- 🌈 무한 무지개 (R)
- ⏩ 게임 속도 조절 (T)
- ⏱️ 타이머 가속 (C)
- 🛡️ 항상 무적 (I)

## 설치 (Chrome / Edge)
1. 초록색 **Code → Download ZIP** 으로 받아 압축 해제
2. `chrome://extensions` 접속 후 우측 상단 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드합니다** 클릭
4. 압축 푼 폴더 안의 **`dovemayo-rainbow` 폴더**를 선택 (manifest.json이 들어 있는 폴더)
5. dovemayo.com 새로고침 후 미니게임 시작

## 안내
- 개인 재미용 도구이며, 이 도구를 쓴 기록은 공식 기록으로 인정되지 않을 수 있습니다.
- 사이트 업데이트로 동작하지 않을 수 있습니다.
